# EVA-UI

NGE UI exploration: recreations of Neon Genesis Evangelion style screens in plain HTML and CSS, with no build step. Studies start CSS only, and vanilla JavaScript is added where a screen needs to be interactive.

Each study is a folder named for its screen type plus a number. Open its `index.html` in a browser to view it.

| Study | Screen |
| --- | --- |
| `W-1` | Warning screen: intrusion alert with a sector label and a seal countdown |
| `C-1` | Countdown screen: seven-segment active time display. Enter a time, press START, and it counts down in milliseconds |
| `M-1` | MAGI screen: the three supercomputers (Melchior, Balthasar, Casper) and their votes. Submit a motion and each computer processes, then votes; two of three decides. A WebGL backdrop draws a hex field and data lines from the state |
